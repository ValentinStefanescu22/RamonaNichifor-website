## Global Constraints (carry over from M1, plus)

- Everything in the M1 plan's Global Constraints still holds: client rules, no visitor cookies, menu order, no 600 weight, artwork never cropped, reduced motion, previews noindex.
- Payload **3.92.0** (supports Next `>=16.3.3 <17`; we run 16.4.3), with:
  - `@payloadcms/next`, `@payloadcms/db-postgres`, `@payloadcms/richtext-lexical`, `@payloadcms/translations`, `@payloadcms/storage-s3`;
  - `sharp`, `graphql` (peer dependency);
  - all `@payloadcms/*` packages pinned to the same version.
- Admin at `/admin`:
  - the UI is in Romanian (`i18n.supportedLanguages: { ro }`, fallback `ro`);
  - noindex, not localised;
  - `/admin` and `/api` are excluded from the next-intl `proxy.ts` matcher and are already disallowed in `app/robots.ts`.
- Payload localization:
  - `locales: ["ro","en"]`, `defaultLocale: "ro"`, `fallback: true`;
  - text, rich text and slug fields are `localized: true`; numbers, dates, colours and relations are shared across locales.
- `versions: { drafts: true }` on every content collection and global.
- Rich text: Lexical, limited to paragraphs, bold/italic, links, lists and h2–h3.
- `users`: `maxLoginAttempts: 5`, `lockTime: 15 min`.
  - The developer admin is created by the seed from `.env.local` test values (`SEED_ADMIN_EMAIL`, `SEED_ADMIN_PASSWORD`, never echoed in chat).
  - Ramona's own account is created by her in M5. Never sign in to her accounts.
- Env:
  - `PAYLOAD_SECRET`, `DATABASE_URI` (local: `postgres://localhost:5432/ramona`);
  - `PREVIEW_SECRET`;
  - S3 vars optional: when `S3_BUCKET` is unset, storage is local disk in `media/` (gitignored).
  - `.env.example` is committed; `.env.local` is gitignored.
- The getters in `content/index.ts` keep their M1 signatures and return shapes, so the components do not change.
- Database changes ship as Payload migrations committed in `migrations/` (`payload migrate:create`).

## Review Focus

1. **Language fallback.** An EN field left empty falls back to RO, so the EN page never shows blanks. Test: blank one EN field and check `/en`.
2. **Slug edits.** A slug changed in the admin must not break the RO↔EN switch: the slug pairs come from `locale: "all"`. Covered by the routing test after the seed and in a test that changes a slug.
3. **Drafts stay private.**
   - A saved but unpublished change never reaches `/` for a public visitor.
   - It does show in Live Preview and in draft mode.
   - Test both.
4. **Uploads.**
   - An illustration upload is stamped and capped.
   - A decorative upload (`illustration` off) is not.
   - Artwork keeps its ratio, no cropping, in every generated size.
   - Test with a fixture image.
5. **Pages without a database.** Pages build and serve without a live DB connection at request time (static + revalidate). A DB outage after build must not 500 the public home. Test: stop Postgres, then `/` still serves.

### Task B2: Seed (parallel after B1)

**What it does:**

### Task B3: Media pipeline, © stamp and screen-size cap (parallel after B1)

**Files:**
- Create:
  - `payload/hooks/stampIllustration.ts`;
  - `assets/stamp/{line.png,corner.png}`, rendered once by a new function in `mockups/scripts/prepare-images.py` (`export_stamp_assets()`) that reuses its existing `stamp()` drawing: the diagonal line and the corner mark on transparent backgrounds, in ink with the cream halo;
  - `tests/media.spec.ts` (or a `node:test` script under `tests/unit/`).
- Modify `payload/collections/Media.ts`: add a `beforeOperation` hook.

**Behaviour:**
- On create/update with `req.file` and `illustration: true` (and no `context.skipStamp`):
  - cap the long edge at 1800 px;
  - composite `line.png` scaled to 84% of the width and centred, and `corner.png` at 2.6% scale bottom-right with a 3% margin;
  - then hand the buffer back to Payload, which makes the sizes.
- No runtime fonts are needed: the stamp is pre-rendered.
- `illustration: false` leaves the file untouched.

- [x] Test with a fixture image (2400×3000):
  - the illustration comes back ≤ 1800 on its long edge with the same ratio, and its pixels differ from the source in the centre band;
  - the decorative image comes back byte-identical in size and dimensions;
  - every generated size keeps the ratio within 0.01.
